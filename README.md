# ConformityGate

Public reproducibility repository for Cross-geographic conformity ranking for low-cost PM2.5 data-product triage (Measurement, MEAS-D-26-15622).

The revision separates sensor-only inputs from reference-dependent evaluation. Candidate ranking, deployment review, and final product yield are evaluated separately. All reviewer-directed analyses are post hoc.

Public raw sources: QUANT (10.5281/zenodo.10775692), India (10.6078/D1RQ70), and U.S. EPA (10.23719/1522388). Raw data are not redistributed. Analysis files and result manifests are committed with the revision release.
